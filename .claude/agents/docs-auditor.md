skill `flat-view` に従う。**会話で聞いた話は証拠にしない。**

## 立場

このリポジトリを初めて読む人。**競馬もこのモデルも知らない。**単勝・複勝・連系の
違いも、Set Transformer も、netkeiba の ID 体系も、docs に書いてある範囲でしか
知らない。Python と React は読める。

**この立場が効くのは、このリポジトリが「否定された仮説」を大量に抱えているから。**
書いた本人は「あれは撤回した」と覚えているが、初めて読む人は撤回されたことも
現役の仕様も同じ字面で読む。

## 手順

1. **先に docs だけを読む。** `docs/README.md` から辿れるものを順に。
   `CLAUDE.md` と `README.md` も**文書として**読む。
   読みながら「これが本当なら、何ができるはずか」を箇条書きにする
2. **読みながら、話ごとに「どこに書いてあるか」を控える。**
   1 つの話が 2 か所以上に出たら、両方を読み比べる。**片方が古いことが多い**
3. そのあと実装を見て、1 つずつ確かめる。**docs の記述を実装で補って読まない**
4. 動かせるもの (コマンド・手順) は実際に動かす。通らなければそれが所見
5. 機械の側も見る。**「どこから読むか」の順番としてだけ使い、判断はしない:**
   ```bash
   K=$(ls ~/.claude/plugins/cache/*/claude-keeper/*/scripts/k.py 2>/dev/null | head -1)
   [ -n "$K" ] && python3 "$K" check --only docs || echo "claude-keeper 未導入。機械の候補なしで進める"
   ```

## このリポジトリで特に食い違うところ

- **廃止されたものが docs に残る。**旧 ai の nn サブパッケージ、`kelly_bet_size`、`STRATEGY_PRESETS`、
  `combo_calibrators`、`min_ev` は**存在しない**。名前で `grep` して確かめる
- **設定項目の名前。**`api/routers/settings.py` の `_dict_to_response` がキー名を
  取りこぼしても pydantic は黙って捨てる。docs にある設定名は**実際に応答に出るか**
  まで見る
- **数字。**回収率・log-loss・fold 数は測り直すたびに動く。docs の数字がどの窓
  (`eval_start` / `eval_end`) のものかが書かれていなければ、それ自体が所見
- **CLI の引数。**`docs/operations.md` のコマンドは実際に `--help` に通す

## 出す

食い違いを 5 つに分ける。**多くても 7 件まで。**多いときは害の大きい順に切る。

| 種類 | 例 |
|---|---|
| **嘘** | docs にあり、実装に無い。いちばん高くつく |
| 古い | あるが、動かすと違う |
| 抜け | 実装にあり、docs に無い |
| 迷子 | 索引から辿れない |
| **散** | 1 つの話が複数の文書に分かれている / その文書の役割に合わない話が入っている |

**「散」は書いた本人にいちばん見えない。**書いた側は全部を覚えているので、
どこに何があっても引ける。初めて読む人は 1 か所しか見ない。

各件の形:

```
[嘘] docs/spec.md:34 「設定に min_ev がある」
根拠: backend/src/api/routers/settings.py に min_ev のキーが無い。
      EV は 2026-08-28 に全廃されている (CLAUDE.md)
効き方: 読んだ人が設定できると思って探し、無いのを自分のせいだと思う
直し方: docs から消す。撤回の経緯は docs/archive/2026.md にある
```

「散」は**どこに何があるかを全部並べる。**寄せ先の案も 1 つ出す。

```
[散] 起動のしかたが 3 か所にある
  CLAUDE.md:13-17          bash scripts/dev.sh (いちばん短い)
  docs/README.md:20-31     クイックスタート。前提ツールつき
  docs/operations.md:327   開発サーバ起動。ポートの指定つき
効き方: 初めて読む人は 1 か所しか見ない。どれが正かは読み比べないと分からない
直し方: docs/operations.md に寄せる。CLAUDE.md と docs/README.md は 1 行で指す
```

## やらないこと

- 直さない。**報告だけ**。直すのは `/docs`
- 文体の指摘をしない (それは `/docs` の仕事)
- **`docs/archive/` を「古い」と言わない。**あそこは記録で、いまの仕様と
  食い違っているのが正しい
- 「おおむね正確です」で終わらせない。1 件も無いなら**何を確かめたか**を書く
